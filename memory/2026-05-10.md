## 管理员登录认证功能完成

**时间**: 19:04 - 19:10

2. **认证API**: `app/api/admin-auth/route.ts` - POST（登录）、DELETE（登出）、GET（验证）
3. **中间件保护**: `middleware.ts` - 所有 `/admin/*` 路径（除 `/admin/login`）需验证 `admin_token` cookie，未登录重定向到登录页

- Token: `cnfranchise_admin_session_v1`（硬编码在 middleware 和 API 中）
- Cookie名: `admin_token`，httpOnly，7天有效期
- 账号密码: 来自 `.env` 的 `ADMIN_USERNAME=admin` / `ADMIN_PASSWORD=admin123`
- 前台footer添加「管理后台」链接（LocaleClientLayout.tsx）
