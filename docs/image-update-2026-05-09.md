# 2026-05-09 图片优化任务总结

## 任务目标
用户反馈文章封面图片与内容关联度不够，需要为品牌文章匹配更精准的图片。

## 执行过程

### 1. 问题分析
- 原有图片匹配策略太泛，所有茶饮品牌都用同一张柠檬茶图片
- 品牌文章（挞柠、霸王茶姬、瑞幸、杨国福、五条人等）需要品牌专属图片

### 2. 解决方案
创建品牌专属图片映射脚本 `scripts/update-brand-images.js`：
- 使用基础slug（不带语言后缀）作为映射key
- 为每个品牌/话题匹配合适的Unsplash图片
- 支持4语言版本（中/英/泰/越）
